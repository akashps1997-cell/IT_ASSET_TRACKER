 Upload employee master (CSV or Excel)

Employee Code is the unique ID. A code that already exists is updated (overwritten with the file's values); a new code is created. You will see a summary to confirm before anything is saved.

Columns: code, name, designation, dept, location (branch), mobile, email, join, status (Active / Resigned / Inactive), exit, remarks, tech. Headings like "Employee Code", "Employee Name", "Department", "Branch", "Joining Date" also work.

Use a .csv file with this header row. Assets are matched on tag: existing tags are updated, new tags are added.

ColumnRequiredFormat / allowed values
tagYesAsset ID, unique, e.g. AST-0001. Cannot be changed later.
nameYesAsset name
typeNoAn Asset Master type (a new type in the file is added automatically)
brand / model / serialNoText
buy / warNoYYYY-MM-DD (purchase date / warranty end)
amount / vendorNoPurchase amount (number) / vendor name
amcNoAMC details
conditionNoNew, Good, Fair, Poor, Damaged
statusNoBlank = automatic. Or Repair, Damaged, Scrap, Retired, Missing
atypeNoEmployee, Branch, Department or In Stock
empIf EmployeeEmployee code, e.g. ELD1929 (active employees)
branchIf BranchBranch name
deptIf DepartmentDepartment name
stocklocNoStock location (In Stock)
loc / notesNoGeneral location / remarks
